Introduction

The Luki API is a RESTful API for the Luki service marketplace.

Overview

The API allows customers to book services and providers to manage their offerings. All requests and responses use JSON format with standard HTTP methods.

Base URL

https://yourdomain.com/api/v1

Quick Start

1. Register

POST /auth/register
{
  "app_type": "customer",
  "first_name": "John",
  "last_name": "Doe",
  "email": "john@example.com",
  "password": "password123",
  "password_confirmation": "password123"
}

2. Verify OTP

POST /auth/register/verify
{
  "email": "john@example.com",
  "otp_token": "...",
  "code": "123456"
}

3. Login

POST /auth/login
{
  "app_type": "customer",
  "email": "john@example.com",
  "password": "password123"
}

Request Headers

Header Value Required
Content-Type application/json Yes
Accept application/json Yes
Authorization Bearer {token} Protected routes
