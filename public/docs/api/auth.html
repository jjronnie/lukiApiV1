Authentication Endpoints

Register, login, password reset, and token management.

Public
POST

/auth/register

Register a new user account. Sends OTP for verification.

Request Body

FieldTypeDescription
app_typestringcustomer or provider
first_namestringFirst name (2-60 chars)
last_namestringLast name (2-60 chars)
emailstringEmail (if no phone)
phonestring+256xxxxxxxxx (if no email)
passwordstringMin 8 chars, letters + numbers
password_confirmationstringMust match password
 
{
  "app_type": "customer",
  "first_name": "John",
  "last_name": "Doe",
  "email": "john@example.com",
  "password": "password123",
  "password_confirmation": "password123"
}
POST

/auth/register/verify

Verify account with OTP. Returns access token.

Request Body

FieldTypeRequired
app_typestringYes
emailstringConditional
phonestringConditional
otp_tokenstringYes
codestringYes
 
{
  "message": "Account verified",
  "data": {
    "user": { "public_id": "usr_...", "first_name": "John" },
    "access_token": "eyJp...",
    "refresh_token": "eyJp..."
  }
}
POST

/auth/login

Login with email/phone and password. Sends OTP.

Request Body

FieldTypeRequired
app_typestringYes
emailstringConditional
phonestringConditional
passwordstringYes
POST

/auth/login/verify

Verify login with OTP and receive access token.

POST

/auth/otp/resend

Resend the OTP code.

Request Body

FieldTypeRequired
otp_tokenstringYes
