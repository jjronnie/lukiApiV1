Introduction

Luki Application codebase documentation.

Overview

Luki is a Laravel 13 application with REST API for a service marketplace.

  • PHP: 8.4
  • Laravel: 13
  • Sanctum: Token-based auth

Directory Structure

FolderPurpose
app/ModelsEloquent models
app/ServicesBusiness logic
app/Http/ControllersAPI Controllers
app/Http/RequestsForm requests
app/Http/ResourcesAPI Resources
app/EnumsEnum constants
database/migrationsDatabase schema

Tech Stack

  • Laravel 13 - Framework
  • Sanctum - API Authentication
  • Fortify - Authentication actions
  • Spatie Permissions - Role management
  • Media Library - File uploads
  • Query Builder - API filtering
  • Pest - Testing
  • TailwindCSS 4 - Frontend

Request Flow

Request → FormRequest (validation) → Controller → Service → Model → Response (Resource)
  1. 1. FormRequest validates input
  2. 2. Controller receives validated data
  3. 3. Service contains business logic
  4. 4. Model interacts with database
  5. 5. Resource transforms to JSON
