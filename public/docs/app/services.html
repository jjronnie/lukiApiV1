Services

Business logic layer in app/Services

DispatchService

Matches orders to providers - finds eligible providers and creates offers.

App\Services\DispatchService

Key Methods

  • dispatch(Order $order) - Create offers for order
  • findEligibleProviders(Service $service, float $lat, float $lng) - Find available providers

PriceEstimateService

Calculates pricing for services.

App\Services\PriceEstimateService

Key Methods

  • estimate(Service $service, ...) - Calculate price
  • applyPricingRules(...) - Apply pricing logic

AuthTokenService

Manages access/refresh tokens.

App\Services\AuthTokenService

WalletService

FcmNotificationService

Sends push notifications via FCM.
