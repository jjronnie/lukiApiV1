Design Patterns Used

  • Service Repository - Services encapsulate business logic
  • Form Request - Validation in separate classes
  • API Resources - Transform models to JSON
  • Traits - Reusable model behavior (HasPublicId)
  • Enums - Type-safe constants

Naming Conventions

  • Models: Singular, PascalCase (Order.php)
  • Tables: Plural, snake_case (orders)
  • Public IDs: Prefix + underscore + random (usr_abc123)
  • Services: Singular, suffixed with Service
  • Enums: Descriptive, suffixed with Status/Type/Mode
